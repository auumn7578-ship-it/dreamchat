# 梦女模拟器

一个纯前端的角色聊天页面：自由输入，AI 以你设定的角色身份实时（流式）回复。
没有后端，直接放到 GitHub Pages 就能用。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（公开仓库即可）。
2. 把 `index.html` 和 `README.md` 上传到仓库根目录（网页上点 **Add file → Upload files**）。
3. 进入仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等一两分钟，页面地址会是 `https://你的用户名.github.io/仓库名/`。

## 第一次使用

1. 打开页面，点右上角 **设置**。
2. 选一个接口预设（比如 DeepSeek），填入你自己的 API Key。
3. 改角色名字、头像、人设、开场白，以及你自己的称呼。
4. 保存后点 **清空对话**，角色会用新的开场白开始。

## 功能

- 流式回复，像对方在打字
- 角色回复里空一行会拆成多条气泡
- （括号里的动作描写）显示为灰色斜体
- 重新回复 / 撤回上一轮 / 清空对话
- 导出、导入存档（导出时不包含 API Key）
- 自动适配手机和深色模式

## 关于 API Key 的安全

Key 只存在你自己浏览器的 localStorage 里，不会写进仓库。
但它是从浏览器直接发给 AI 服务商的，所以：
- 不要把 Key 写进代码再上传；
- 不要在公用电脑上保存 Key；
- 建议在服务商后台给这个 Key 设置额度上限。

部分服务商（如 OpenAI）可能不允许浏览器直接跨域调用，遇到 CORS 报错时换 DeepSeek、OpenRouter 等即可。
